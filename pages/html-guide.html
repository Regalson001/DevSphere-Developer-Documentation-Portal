HTML5 Semantic Elements Reference

Writing meaningful markup using native elements to enhance machine readability, SEO rankings, and assistive screen reader navigation.

Why Semantics Matter

Semantic markup clearly describes its meaning to both the browser and the developer. Instead of generic <div> wrappers everywhere, semantic tags give structure to content sections.

Key Semantic Landmarks

  • <header>: Represents introductory content or navigational links.
  • <nav>: Defines a section intended for major navigation links.
  • <main>: Specifies the dominant content of the document body.
  • <aside>: Content tangentially related to the content around it (sidebars).
  • <footer>: Footer for a nearest sectioning content or root element.
